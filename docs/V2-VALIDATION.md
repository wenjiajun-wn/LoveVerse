## 覆盖范围

- Markdown 解析、序列化、正文与扩展 metadata 保留、非法 YAML、损坏文件拒绝覆盖。
- CRUD、旧版本冲突、备份、路径遍历、符号链接、公开目录作为存储根的拒绝。
- 密码验证、会话撤销与过期、密码变更后失效、伪造身份上下文、未授权 API、Origin 检查、登录限速、演示模式拒绝私人 API。
- 全文与组合筛选、React 文本高亮、Markdown XSS 与外链内容限制。
- 图片真实解码和重新编码、非法格式与大小、未登录图片访问、禁止删除被引用照片。
- 纪念日确认导入、去重、一次性标记、并发冲突；原日期测试继续覆盖上海日历日期和闰日周年。
- 浏览器执行登录、上传、创建、搜索、预览、编辑、取消删除与确认删除，七条回忆分页、照片墙与时间轴适配、另一浏览器同步纪念日、注销后旧会话不可用。
- 未登录 HTML 不包含私人故事；静态私人路径不可访问；导入不删除原 localStorage。

测试使用临时目录与虚构账号，私人 E2E 在结束时清理测试目录，不使用真实情侣资料。桌面日记、手机编辑器与日记截图已人工检查，新增布局延续原色彩与组件，手机无横向溢出。
