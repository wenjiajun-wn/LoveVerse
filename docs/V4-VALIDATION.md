## 安全与业务覆盖

1. API 匿名、跨站、伪造上下文、非法路径及私人图片访问边界。
2. 另一成员不能列出/修改/删除惊喜，不能导出他人的回忆录 PDF。
3. 胶囊创建响应/锁定 dashboard 不含正文和附件；伪造图库路径无法访问封存照片；到期后合法成员可访问且 no-store。
4. 章节筛选、来源日期/地点不可伪造、编辑版本冲突、重新生成预览和删除 revision。
5. 没有来源不调用模型，虚构引用拒绝；授权撤销后不发布；Provider 故障不写新草稿，旧回忆仍可读。
6. 惊喜总预算/总时长校验，模型工具调用拒绝；外部通知适配器即使传入许可参数也拒绝发送。
7. 提醒任务独立凭据、并发去重、重跑不重复、停机补偿、已读状态、关闭偏好、平年闰日、未来首次周年和跨时区日期。
8. Markdown 预览复用 V2 的禁原始 HTML/外部图片/活动链接渲染；PDF 对文本转义，浏览器禁止脚本和网络。
9. V1 星球、相册、时间轴、纪念日和小游戏，以及 V2 CRUD/上传/导入/退出、V3 同意/问答/来源/清除/导出回归。

## 交付边界

本地代码已提供完整私人功能与可安装的主动提醒方案。正式离线提醒需要常在线主机和实际安装计时器；没有声称用户电脑关机时本地服务仍能运行。游戏为同屏轮流作答，暂不包含跨设备实时联机。抽取式 AI 章节优先保证来源真实性，不提供无来源的自由编造式长篇回忆录。
