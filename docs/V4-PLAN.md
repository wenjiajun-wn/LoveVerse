# LoveVerse V4 计划与后续工作

本文件替代修改包内的初版计划，详见 [集成基线](V4-INTEGRATION.md) 与 [架构](V4-ARCHITECTURE.md)。

## 本阶段

- 审查干净 V3、14 文件修改包并在 codex/v4-love-companion 增量开发。
- 完善结构化章节、受控 AI 摘录、来源、排序、照片与双主题服务端 PDF。
- 私人惊喜预算/时长校验、编辑文案和跨成员隔离。
- 胶囊封存附件、日期和删除版本边界。
- 确定性提醒调度、持久化去重、补偿、时区与通知记录；常在线部署模板。
- 往年今日原始详情/确认导出和四种双人游戏。
- 完整权限/Mock/API/浏览器/构建回归和文档。

## 正式部署前（需要账号/环境选择）

1. 用户选择常在线宿主机、持久磁盘、域名及两个 Access 邮箱；配置凭据，先用虚构数据验证。
2. 在目标 Linux 主机安装中文字体/Chromium，验证 PDF、systemd timer、停机恢复、磁盘权限与备份恢复。
3. 按部署文档执行 Cloudflare Access 和图片/API 拦截矩阵，禁止未保护源站。
4. 如需外部消息，确认官方资格、收件人订阅及双方许可，再实现凭据管理、outbox、退订与限速；本阶段所有外部适配器禁用。

## 可选后续迭代

- 跨设备实时双人对战（当前为同设备交接独立作答）。
- 更丰富的书册字号、封面与纸张选项；批量档案归档和备份保留管理。
- 官方渠道通知与错误告警，但不得读取个人聊天数据库或自动交易。
- 语义生成必须保留明确来源和人工审阅，不能将创意当成历史事实。
