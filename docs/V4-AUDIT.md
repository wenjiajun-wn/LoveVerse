## 保留并验证的安全设计

- 私人接口通过 authenticate/privateRoute，服务再校验不可伪造的 IdentityContext；新情侣配置读取器同样 authorize。session 响应 no-store。
- Cookie 为 HttpOnly、SameSite=Strict，HTTPS 时 Secure；变更请求检查 Origin。账号凭据变化与会话撤销会阻止访问。
- Markdown 默认不执行 HTML；私人文件 server-only，路径与 UUID 校验，原子写入、锁、revision 和备份保持原状。
- 上传验证格式/字节/像素、重新编码并去元数据；图片 GET 鉴权且 no-store，不使用公开图片优化代理或公共缓存。
- V4 秘密计划按创建者隔离，胶囊未到期不返回正文/附件；PDF 禁止网络和脚本；提醒任务使用独立凭据和去重。
- AI 保留原有双方逐条授权、预算、只读工具与来源核验；关闭时在调用 Provider 前拒绝。日志仅记录运行指标，不打印私人正文或密钥。

## 剩余风险与人工验收

- 未读取真实私人数据，因此无法判断既有日记中是否曾手动导入演示故事；需用户自行核实，不能自动清空。
- 未代填情侣资料或自动切换运行模式。真实称呼、日期、双方账号由用户按教程设置。
- 文件存储面向小规模双人空间，列表仍读取全部回忆；未进行 1000 条大正文与大量高分辨率照片的真实设备压力测试。不要在真实数据上压测。
- 当前会话通过聚焦/定时检查撤销状态，离线已显示页面不能远程立即抹除；离开共享设备应主动退出。
- 初次加载若减少动态效果，切回动画需重新加载页面；不会影响内容访问。
- 未执行真实 DeepSeek 联调、外网/Access 配置验收、生产调度任务与灾难恢复演练。真实云端模型保持关闭。
- 部署仍需独立持久存储、操作系统权限、HTTPS 与备份管理；测试通过不替代生产环境配置验收。
