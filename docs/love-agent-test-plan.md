# Love Agent 测试与验收

## 分层测试

- `tests/unit/agent.test.ts` 使用临时目录、虚构双人账号、真实 V2 身份/MemoryService 与 Mock Provider/fetch。路由集成覆盖完整认证 → 工具 → 回答/引用链路，不依赖真实密钥。
- `tests/private-e2e/agent.spec.ts` 使用真实登录/许可/来源 API，明确 Mock 聊天响应，验证重试、来源弹窗、清除/导出与手机布局。服务强制空 DeepSeek 密钥，防止误发云端请求。
- `tests/e2e/agent-demo.spec.ts` 验证公开 AI 入口不请求私人接口。原 V1/V2 测试全部保留。
- `scripts/check-agent-bundle.mjs` 扫描客户端构建的 canary 与服务端密钥标识。

## 覆盖用例

授权搜索与真实来源；无记录不编造；同名日期/地点冲突；未登录、伪造身份、跨站、客户端 userId；单人同意、未共同选择、编辑、撤销；secret 覆盖；Markdown 提示注入请求写工具/路径/URL 被拒绝；DeepSeek 超时/429/503/取消；非法参数/分页/工具轮数/引用/虚构事实；密钥不进入日志/响应；V2 在 AI 故障时可继续使用。
