# 私人数据填写教程

本轮没有替你填写称呼、日期或故事，没有读取或迁移已有真实照片和日记。公开演示仍保留 `src/data/demo.ts`；不要将私人资料写进这个文件。

## 1. 配置私人环境

在仅由服务器管理的 `.env.local` 中填写以下字段，不使用 `NEXT_PUBLIC_` 前缀。文件已忽略，勿提交或分享。

```dotenv
LOVEVERSE_MODE=private
LOVEVERSE_ORIGIN=http://localhost:3000
LOVEVERSE_COUPLE_NAMES=""
LOVEVERSE_COUPLE_START=
LOVEVERSE_AI_ENABLED=false
LOVEVERSE_AI_PUBLIC_DEMO=false
```

在称呼引号内填写你们希望展示的称呼，最多 80 个字符；相恋日期填写真实的 `YYYY-MM-DD` 日历日期。日期必须存在（例如平年不能填 2 月 29 日）。留空或非法日期显示空状态，不会采用演示情侣的日期。首页与纪念日共用这个值，按 Asia/Shanghai 计算；闰日周年沿用平年 2 月 28 日规则。

已有私人环境请保留原来的 `LOVEVERSE_DATA_DIR`、账号与 origin，不复制示例覆盖它们。首次环境执行 `npm run private:setup`，按提示建立双方独立账号；不要把初始化输出发到 GitHub。公开演示与私人环境应使用独立进程和数据目录。

修改环境变量后重启服务。开发使用 `npm run dev`。生产本地验证先停止原进程，执行 `npm run build`，再 `npm run start -- --hostname 127.0.0.1`，避免旧服务和新构建资源错配。浏览器地址须与 origin 一致。

## 2. 写真实故事和上传照片

登录 →「恋爱日记」→「新建回忆」。填写标题、回忆日期、地点、分类、标签和 Markdown 正文，通过现有上传按钮选择自己的照片，再保存。可以编辑；删除需要确认且保留服务端备份。

上传目前支持实际解码有效的 JPEG、PNG、WebP，最大 8MB、1600 万像素，不支持动画；服务器纠正方向、缩至最长边 2400、重新编码 WebP 并去除元数据。不要直接向 `public/` 复制私人图片。

保存后星球、照片墙、时间轴和详情使用同一份认证记录；Companion 在打开时读取私人服务。首页优先取最近回忆中的封面，缺少图片显示占位。没有回忆时不会自动填充故事。旧版回忆问答需要至少三个不同日期；通用偏好测试和盲盒仍可使用，盲盒只是未来活动建议。

## 3. 添加纪念日

「纪念日」→「添加一个期待」，填写真实名称、日期和是否每年重复。私人模式保存至服务器；另一设备打开页面或重新聚焦后同步。

浏览器旧数据仅在明确确认后导入一次，不会删除 localStorage。请先核实旧记录是否属于你们，勿把曾经试用的演示记录误导入。

## 4. 关闭 DeepSeek

保持两个 AI 开关为 `false` 后重启。本轮已将当前 `.env.local` 的两个开关关闭，并保留其他配置与密钥。关闭后可以继续写日记、上传照片、管理纪念日及使用不依赖 AI 的 V4 功能；AI 生成功能不会调用模型。将来重新开启仍需双方同意和逐条当前版本授权，不会自动把全部回忆发送给模型。

## 5. 私人分享

沿用 README 和 V4 部署文档：持久 Node 服务、HTTPS 固定域名、正确 origin、Cloudflare Access 仅允许双方账号，保护整站及所有 API/图片路径，并保留应用自身登录。源站不要直接暴露公网。更换配置后用未登录窗口核验私人接口拒绝访问。

本轮未建立 Tunnel、修改 DNS、启用外部通知或发布站点。真实跨设备网络、Access 策略、主机备份恢复需要在你的部署环境人工验收。
