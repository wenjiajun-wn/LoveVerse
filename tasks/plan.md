## V3 增量计划

需求来源：用户指定的 LoveVerse_V3_DeepSeek_Codex_Prompt.md，已读取。基线 32 项单测与 typecheck 通过；V2 未提交更改全部保留，V3 分支 feat/love-agent-v3。

1. 同意与 Provider：默认关闭；双方独立同意、逐条版本授权；服务端官方 API、超时取消与限额。验收：未授权不发请求，密钥不进入客户端。
2. Memory Tools：只读注册表、严格参数、有限分块、重复授权。验收：非法工具/路径/未共享回忆拒绝，工具不读仓库文件。
3. Agent Service：最多三次模型请求、两轮工具、引用绑定及回复前复查。验收：无资料固定回复；无效来源不展示，事实与推断分类。
4. 聊天 UI：新增 Hash 入口、同意管理、发送/取消/重试、清除/导出、现有详情弹窗来源卡。验收：手机可用，不改变旧页面。
5. 测试文档：模拟模型，不向真实云端发送数据；单元/权限/Provider/浏览器与 V1/V2 回归；更新环境示例与架构。

风险：V2 所有回忆 visibility=private，不能默认外发；双人共同空间而非多租户，沿用原授权范围；内容更新使旧 AI 许可失效。不保存聊天到服务端，不发送照片，不赋予写工具。先非流式完成校验再展示。API 故障与 AI 关闭不影响 V2。

Skills：已阅读 planning-and-task-breakdown、senior-backend、agent-harness；使用规划方法，现有模块化 Node 架构足够，不运行完整 Harness、不引入数据库或额外框架。按用户明确要求规划后直接实施。

后续用户明确要求暂不配置账号，先公开使用 AI：新增独立公开演示数据源和受 Origin/同意/限额约束的匿名问答接口，仅可读取 demo.ts；私人入口继续认证。57 项单元/集成测试、18 项公开与 12 项私人浏览器测试通过，并完成只使用公开故事的真实 DeepSeek 全链路检查。
